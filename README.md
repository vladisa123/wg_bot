# wg-bot

Telegram-бот раздачи VPN-конфигов: WireGuard и Shadowsocks.
Пользователь жмёт «Создать конфиг» — бот генерирует ключи, добавляет пира
в `wg0.conf` на VPN-сервере (по SSH) и присылает `.conf`/`ss://` ссылку.

## Устройство

- `bot.ts` — весь бот на Deno, один файл, без зависимостей
- `clients.json` — выданные конфиги (имя, tg_id, IP, ключи)
- `names.json` — соответствие tg_id → имя
- `whitelist.json` — кому разрешено создавать конфиги
- `requests.json` — заявки на доступ

## Запуск

```bash
cp .env.example .env   # заполнить
set -a && . ./.env && set +a
deno run --allow-all bot.ts
```

Как systemd-сервис — см. `wg-bot.service`.

## Переменные окружения

Все секреты (токен бота, пароль Shadowsocks, ключ сервера) задаются только
через `.env`. В коде дефолтов нет намеренно.

## Важно

- Бот правит `/etc/wireguard/wg0.conf` **на удалённом сервере** через SSH.
  Нужен ключ в `/root/.ssh` и `authorized_keys` на сервере.
- В `writeRemoteConf` есть защита: конфиг с меньшим числом пиров, чем живёт
  сейчас, не заливается — иначе wg syncconf снесёт всех клиентов.
